### Flyway & Base de Datos (H2)
- El proyecto utiliza **H2 en memoria** (`jdbc:h2:mem:tododb`).
- `flyway.enabled: true`: Las migraciones en `src/main/resources/db/migration/V{n}__{descripcion}.sql` son la **única fuente de verdad** del esquema de base de datos.
- `spring.jpa.hibernate.ddl-auto: none`: Hibernate no altera el esquema automáticamente; solo Flyway ejecuta las migraciones.
- **Convenciones del Esquema**:
  - `users`: Utiliza **`UUID`** como clave primaria.
  - Otras tablas (`refresh_tokens`, `categories`, `tasks`, `subtasks`): Utilizan **`BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`** (autoincremental).

### Convención de Consultas JPQL Dinámicas
- Para endpoints con filtros opcionales (ej. `userId`, `categoryId`, `status`, `isRevoked`), se utiliza el patrón de evaluación nula en `@Query`:
  ```java
  @Query("SELECT e FROM Entity e WHERE (:param IS NULL OR e.field = :param)")
  ```
  Esto permite que Spring Data y la base de datos gestionen el filtrado en una sola query sin necesidad de construir `CriteriaBuilder` o múltiples métodos en el repositorio.

## 🧪 Estándares de Testing (JUnit 5, Mockito & MockMvc)
- **JUnit Jupiter (`@Nested`, `@DisplayName`, `@ParameterizedTest`, `@NullAndEmptySource`, `@ValueSource`)**: Para pruebas expresivas de Value Objects, Modelos y Mappers.
- **Mockito (`@ExtendWith(MockitoExtension.class)`, `@Mock`, `@InjectMocks`)**: Para aislar casos de uso (`*ServiceTest`) y adaptadores de persistencia (`*AdapterTest`) sin levantar el contexto de Spring.
- **MockMvc Standalone (`MockMvcBuilders.standaloneSetup(controller).setControllerAdvice(new GlobalExceptionController()).build()`)**: Para probar controladores REST (`*ControllerTest`) y el mapeo de `DomainException` a `ErrorDto` de manera rápida y determinista.

## 🪵 Trazabilidad y Logs
- Uso de la anotación **`@Log` de Lombok** (`import lombok.extern.java.Log;`) que inyecta un `java.util.logging.Logger log`.
- **Dónde aplicar logs obligatoriamente**:
  1. **Controladores (`controller`)**: Entrada de peticiones HTTP con parámetros (`log.info`) y confirmación de respuesta enviada.
  2. **Servicios (`service`)**: Inicio de operaciones de negocio (`log.info`) y advertencias ante recursos no encontrados o conflictos (`log.warning`).
  3. **Adaptadores (`repository/adapter`)**: Interacción con la base de datos (`log.info`).
  4. **Manejador Global (`GlobalExceptionController`)**: Excepciones de dominio interceptadas (`log.warning`) y errores 500 no controlados (`log.severe`).
